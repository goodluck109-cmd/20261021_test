# ☕ 오늘의 카페 — 반응형 카페 주문 웹앱

커피와 디저트 메뉴를 소개하고, 원하는 수량을 선택하면 총 주문 금액을 자동으로 계산하는 한국어 카페 주문 웹페이지입니다.

## 주요 기능
- PC, 태블릿, 스마트폰에 대응하는 반응형 화면
- 8개 메뉴의 일러스트, 설명, 가격 표시
- 메뉴 수량 추가·감소 및 총금액 자동 계산
- 클릭 효과음과 버튼으로 켜고 끄는 카페 분위기의 배경음
- 주문 완료 메시지와 지원 브라우저의 한국어 음성 안내
- 단일 HTML 파일로 실행 가능하며 설치나 서버가 필요 없음

## 실행 방법
1. `index.html`을 다운로드합니다.
2. 파일을 더블 클릭해 Chrome 또는 Edge에서 엽니다.
3. 메뉴 수량을 선택하고 총금액을 확인한 뒤 주문하기를 누릅니다.

## 기술
- HTML, CSS, Vanilla JavaScript
- Web Audio API를 이용한 클릭음 및 생성형 배경음
- 브라우저 `speechSynthesis`를 이용한 한국어 음성 안내
- 별도 이미지 파일 없이 HTML 안에 포함된 메뉴 일러스트 사용

## 참고
- 브라우저의 자동 재생 정책 때문에 배경 음악은 사용자가 음악 버튼을 눌러 시작합니다.
- 음성 안내는 브라우저와 기기의 한국어 음성 지원 여부에 따라 달라질 수 있습니다.
- 실제 결제나 매장 주문 접수 서버는 포함하지 않은 시연용 프로젝트입니다.
